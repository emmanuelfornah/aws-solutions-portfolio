# AWS Labs Portfolio

A curated collection of hands-on AWS labs demonstrating practical cloud engineering skills across compute, storage, databases, networking, security, and DevOps.

## 🎯 Portfolio Overview

This portfolio showcases real-world AWS implementations built through hands-on labs. Each lab demonstrates practical skills in designing, deploying, and managing cloud infrastructure.

## 📚 Lab Categories

### [Compute](./compute/)
- **[WordPress on EC2](./compute/01-wordpress-on-ec2/)** - Full-stack web application deployment with Apache, MariaDB, and WordPress on EC2 with Network Load Balancer
- **[Flask on Elastic Beanstalk](./compute/02-flask-elastic-beanstalk/)** - Python web application deployment using AWS Elastic Beanstalk with auto-scaling and load balancing

## 🛠️ Skills Demonstrated

- **Infrastructure Design**: VPC architecture, load balancing, auto-scaling
- **Compute Services**: EC2, Elastic Beanstalk, application deployment
- **Database Management**: MariaDB setup, user management, security
- **Web Server Configuration**: Apache, SSL/TLS, virtual hosts
- **Application Deployment**: WordPress, Flask, Python applications
- **DevOps Practices**: CLI automation, configuration management, version control
- **Security**: File permissions, database security, SSL certificates

## 📖 How to Use This Portfolio

Each lab folder contains:
- **README.md**: Lab overview, architecture, learnings, and setup instructions
- **Scripts**: Automation scripts for deployment and configuration
- **Configs**: Configuration files and samples
- **Application Code**: Source code for deployed applications

## 🚀 About These Labs

These labs represent hands-on learning experiences focused on practical AWS skills relevant to cloud engineering roles. Each implementation follows AWS best practices and demonstrates real-world scenarios.
